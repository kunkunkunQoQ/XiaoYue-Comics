## 🏛️ 多系列结构组织说明

公开漫画仓库自 2026-10-17 起规范化为多系列架构。未来所有同看板娘但不同世界观的新系列均遵循以下标准平级存放：

```text
series/
├── README.md                      # 📚 全部系列索引（本页面）
├── xiaoyue-daily/                 # 🍳《小跃的奇妙日常》专属空间
│   ├── README.md                  # 系列目录与阅读指南
│   ├── chapters/                  # 正篇按话数英文 slug 组织
│   └── extras/                    # 独立番外按短码英文 slug 组织
└── <future-series-slug>/          # 🚀 未来新系列（拥有独立目录，互不干扰）
```

> 💡 **阅读小贴士**：不同系列之间不自动继承世界观规则或人际关系；独立番外亦不继承正篇剧情连续性。无论从哪个系列、哪篇独立番外读起，都能轻松享受阅读乐趣！
